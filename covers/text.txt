
## 🚀 Cómo añadir un juego

1. Abre `script.js`
2. Busca el array `juegos` y añade un nuevo objeto con esta estructura:

```javascript
{
    id: 13,                      // Número único
    titulo: "Nombre del Juego",
    sistema: "snes",             // nes, snes, megadrive, ps1, ps2, gamecube, xbox360, switch, ps5
    año: 1990,
    genero: "Plataformas",
    desarrolladora: "Nintendo",
    descripcion: "Breve descripción del juego.",
    cover: "covers/mi_cover.jpg", // O URL completa
    download: "https://enlace-externo.com/juego"  // O "#" si no tienes
}



---

## 📝 Resumen para ti

1. **Crea la carpeta `covers/`** en la raíz y pon tus imágenes dentro.
2. **Edita `script.js`** para añadir tus juegos. Cada juego tiene:
   - `cover`: `"covers/mi_juego.jpg"` (si la imagen está en esa carpeta)
   - `download`: Pon `"#"` si aún no tienes enlace, o la URL cuando la tengas.
3. **Sube todo a GitHub** y activa Pages.
4. **Los filtros funcionan** por sistema, búsqueda y vista cuadrícula/lista.
